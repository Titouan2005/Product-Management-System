# Product Management System

A starter **Next.js 16 / React 19 / TypeScript** web app with Tailwind CSS. It has a home page, a profile page and a search page. I built it in lab sessions as the base for my full product management app, [Project_RWA](https://github.com/Titouan2005/Project_RWA).

## Tech stack
- Next.js 16 (App Router), React 19, TypeScript
- Tailwind CSS 4
- ESLint

## Pages
| Route | Content |
|---|---|
| `/` | Home |
| `/profile` | User profile page |
| `/search` | Search page |

## Run it
```bash
cd 2026-DemoApp-main
npm install
npm run dev
```
Then open http://localhost:3000.
